# 证据、引用与学术诚信

> 研究生最容易踩的坑不是"不会写"，是"写得很像真的"。这份文件是硬规则，所有产物都适用。

---

## 1. 三级标签：让读者知道这句话有多硬

| 标签 | 含义 | 使用条件 | 写法 |
| :--- | :--- | :--- | :--- |
| 【文献】 | 有可核验的出处 | 你点开过原文/摘要，能给出 DOI/链接 | 句尾标【文献】+ 出处 |
| 【经验】 | 领域常识、实践证明、师兄师姐经验 | 无单一出处，但圈内普遍认可 | 句尾标【经验】 |
| 【推测】 | 没有证据，只是合理猜测 | 必须显式说明"未检索验证" | 句尾标【推测】 |

规则：
- 连续 3 句判断至少带 1 个标签；纯描述句（"本文使用的数据集是 X"）可豁免。
- 【推测】不能写成【文献】；不确定就降级，不要升级。
- 标签不是免责声明，是给读者判断权重的工具。

---

## 2. 引用核验 SOP

每一条要写进开题/论文的引用，按顺序过一遍：

1. **点开**：DOI/arXiv 能打开，标题、作者、年份、venue 对得上。
2. **读摘要**：至少读摘要，确认它真的支持你这句话。
3. **查撤稿/更正**：Retraction Watch、期刊官网、PubMed 的 correction/erratum 标记。
4. **查 predatory**：期刊是否在 Beall 名单/学校预警名单；会议是否正规。
5. **区分版本**：预印本 vs 正式发表；会议版 vs 期刊扩展版；数字可能不同。
6. **记录**：作者、年份、venue、DOI、你读的是哪一版、它支持哪一句。

**没有 DOI 的引用**：给出可访问链接 + 访问日期；仍无法核验的，标"无法核验"，不要写成确定结论。

---

## 3. 检索要留痕

开题、综述、论文的方法部分都需要说明你怎么找文献。至少记录：

| 字段 | 例子 |
| :--- | :--- |
| 数据库 | Web of Science、Scopus、PubMed、arXiv、CNKI |
| 检索式 | ("stress detection" OR "stress recognition") AND wearable |
| 时间范围 | 2019-01 至 2026-10 |
| 语言 | 英文 + 中文 |
| 命中/去重/纳入 | 312 / 198 / 47 |
| 筛选标准 | 可穿戴、自然场景、有量化评测；排除纯综述/无全文 |

**检索式要能复现**：别人照着你写的检索式，应该能得到相近的结果。

---

## 4. 禁止话术与替代表达

| ❌ 不要写 | ✅ 改成 |
| :--- | :--- |
| "没有人做过" | "截至 {日期}，在 {数据库} 用 {检索式} 未检索到 {设定} 下的研究" |
| "大量研究表明" | "已有 N 项研究（{引用}）表明" |
| "显著提升"（无数字） | "提升 {x} 个百分点（{数据集}，{划分}，N=…）" |
| "国际领先" | "在 {基准} 上达到 {数字}，与 {SOTA} 相差 {…}" |
| "必然/一定/保证" | "在当前证据下，较可能……；若 {条件} 改变，结论需重估" |
| "填补空白" | "在 {设定} 下提供了首个 {评测/数据/基线}" |
| "效果很好" | "在 {指标} 上从 {a} 到 {b}，效应量 {…}" |
| "据说/听说" | 找到出处，或标【经验】/【推测】 |

---

## 5. 数字规范

- 不编造：样本量、准确率、接受率、审稿周期、影响因子、引用数。
- 不确定：写"约"、"据 {来源} 报告"、"官网未公开"。
- 比较：不同数据集/划分/指标的数值**不能直接横比**，必须说明口径。
- 显著：区分"统计显著"和"实际重要"；报告效应量与置信区间。
- 示例：样例/演示里的数字必须标"示例数据，非真实结果"。

---

## 6. 图表与结果

- 一张主图讲清方法，一张主表讲清结果；不要用 10 张图堆工作量。
- 图注要能独立读懂：数据、指标、误差棒、样本量。
- 不裁剪坐标轴误导差异；不隐藏失败样本。
- 复现实验：固定种子、记录环境、数据版本、代码链接。
- 负结果如实报告；选择性报告是学术不端。

## 7. AI 使用边界

### 可以做

- 头脑风暴、列提纲、改语言、查逻辑漏洞、模拟审稿人。
- 解释概念、调试代码、整理文献矩阵（前提：你自己核对过）。
- 把长文压缩成要点（前提：你读过原文）。

### 不可以做

- 让 AI 生成未读文献的"总结"并当作自己读过的。
- 让 AI 编数据、编结果、编引用。
- 让 AI 代写正文并当作自己写的。
- 隐瞒 AI 使用（学校/期刊要求声明时）。

### 声明模板

> 本文写作过程中使用了 {工具名} 辅助 {语言润色/结构梳理/代码调试}；所有文献、数据与结论均由作者本人核验，文责自负。

**学校/期刊的政策优先于本文件。** 投稿前查作者指南中的 AI 条款；不确定就写信问编辑。

---

## 8. 数据、代码与伦理

- 人类被试：伦理审查（IRB）在实验前完成，知情同意齐全；涉及未成年人/患者另有规定。
- 个人数据：脱敏、最小化收集、明确用途与保存期限；遵守学校与法规要求。
- 数据共享：能公开就公开（附说明）；不能公开要说明原因与申请方式。
- 代码：给运行环境、依赖、种子、示例命令；能让别人跑通才算"可复现"。
- 作者署名：按实际贡献，和导师/合作者提前谈清；不要挂名，也不要漏名。
- 利益冲突：基金、企业合作、专利，按期刊要求披露。

---

## 9. 交付前自检（30 秒）

1. 每个 DOI 都点开过吗？
2. 每个数字都有来源或标了"推测/示例"吗？
3. 有没有把"我猜"写成"研究表明"？
4. 最接近的 3 篇工作，我能不能说出差异？
5. 结论在什么条件下不成立，我写了吗？
6. AI 使用符合学校/期刊规定吗？
7. 如果导师/审稿人追问，我答得出来吗？

有一项答不上来，就不要交付。
