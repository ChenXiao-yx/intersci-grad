# 研究生产物模板

> 复制即用。填不满就说明还没想清楚，不要用空话凑。
> 所有模板都遵循同一个骨架：**一句话判断 → 为什么 → 三条路 → 下一步（今天/本周/两周）→ 依据 → 待确认**。
> 交付前删掉用不到的示例行，默认控制在一页内。

---

## 1. 选题卡

```markdown
# 选题卡：{方向}

**一句话判断**：{可做 / 需收窄 / 换题 / 先补预实验}（置信度 {x}%）

**为什么**：{最关键的一条依据 + 最大的不确定性}。

## 候选题目

| # | 研究问题（一句） | 新在哪 | 数据/资源 | 风险 | 推荐 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| A | {在什么设定下回答什么问题} | {新问题/新方法/新证据/新场景} | {数据集/设备/被试} | {最大风险} | ⭐ |
| B | … | … | … | … | |
| C | … | … | … | … | |

## 缺口陈述（可直接写进开题）

现有工作主要在 {场景} 用 {方法} 解决了 {问题}【文献】。但在 {你的约束} 下，
{指标/可用性} 会 {下降方式}【文献/经验】。因此本文要回答：{主问题}。

## 最小可发表单元（MPU）

- 主图：{一张什么图}
- 对照：{和谁比}
- 数据：{从哪来、多少、怎么划分}
- 一句贡献：{以前不知道什么，现在知道了什么}

## 三条路

| 路线 | 做什么 | 代价 | 适合 |
| :--- | :--- | :--- | :--- |
| 保守 | {换约束/换评测，风险最低} | {时间/资源} | {赶毕业} |
| 主流 | {当前最可能发的中等方案} | … | {常规} |
| 冒险 | {新方法/新场景} | … | {时间充足} |

## 下一步

- 今天（30 分钟）：{检索 3 组关键词，记录命中数}
- 本周：{读完 5 篇最接近的，填文献矩阵}
- 两周：{跑通 MPU 的第一个 baseline}

## 依据

- 【文献】{作者/年份/DOI}
- 【经验】{领域常识/师兄经验}
- 【推测】{没有证据的判断}

## 需要你确认

{最多 1 个会改变结论的问题；没有就写"无"}

> 本文件由 AI 辅助整理，引用与数据请自行核验；不替代导师意见与学校规范。
```

## 2. 开题一页纸

```markdown
# {题目}：开题一页纸

**一句话判断**：{这个题目成立 / 需要收窄到 X / 建议换 Y}（置信度 {x}%）

**为什么**：{缺口 + 你的独特条件}。

## 1. 现象与缺口

{现实中发生什么}。现有研究 {做到哪}【文献】，但 {没解决什么}【文献/经验】。

## 2. 研究问题

- 主问题：{一句}
- 子问题 1：{一句}
- 子问题 2：{一句}

## 3. 假设（可证伪）

- H1：{如果……则……}
- H2：{如果……则……}

## 4. 方法

{数据} + {方法} + {对照} + {指标}。关键洞察是 {一句话}。

## 5. 证据标准

- 支持：{什么结果算支持}
- 推翻：{什么结果算推翻}
- 失败判据：{提前写，防止自欺}

## 6. 贡献

1. 首次在 {条件} 下 {证明/发现} {结论}。
2. 给出 {数据/代码/基线/评测协议}。
3. 发现 {A 与 B 的权衡/边界}。

## 7. 计划与风险

| 阶段 | 产出 | 时间 | 风险 | 降级方案 |
| :--- | :--- | :--- | :--- | :--- |
| 预实验 | {基线} | {周} | {…} | {…} |
| 主实验 | {主表} | {周} | {…} | {…} |
| 写作投稿 | {初稿} | {周} | {…} | {…} |

## 下一步

- 今天（30 分钟）：{把七句逻辑链读一遍，标出断点}
- 本周：{补 3 篇最接近的文献，写差异}
- 两周：{完成预实验并给导师看一页结果}

## 需要你确认

{最多 1 个问题}

> 本文件由 AI 辅助整理，引用与数据请自行核验；不替代导师意见与学校规范。
```

## 4. 单篇精读卡

```markdown
# 精读卡：{标题}

**一句话判断**：{这篇值得精读/只读摘要/可以跳过}；对我最大的用处是 {…}。

**出处**：{作者}，{年份}，{期刊/会议}。[DOI/arXiv]({链接})

## 五问

1. **问题**：{它要解决什么，为什么难}
2. **方法**：{核心洞察，不是模型名}
3. **证据**：{数据/指标/对照，结论强度}
4. **局限**：{作者承认的 + 我看出的}
5. **与我的关系**：{支撑/反对/baseline/数据/方法可借用}

## 可复用

- 数据：{…}
- 代码：{链接}
- 指标/协议：{…}
- 实验设计：{…}

## 可攻击点

- {假设不成立的地方}
- {评测没覆盖的地方}
- {换数据集可能失效的地方}

## 下一步

- 今天（30 分钟）：{记下 3 个可复用点}
- 本周：{决定是否纳入 related work}
- 两周：{若能复现，跑通 baseline}
```

## 5. 实验设计卡

```markdown
# 实验卡：{实验名}

**一句话判断**：{这个实验能/不能验证 H1}；最大的风险是 {…}（置信度 {x}%）

**为什么**：{假设 + 最关键的控制变量}。

## 假设

{如果……则……；什么结果算推翻}

## 设计

| 项 | 内容 |
| :--- | :--- |
| 自变量 | {改什么} |
| 因变量 | {测什么，单位，方向} |
| 对照 | {经典 / SOTA / 简单强基线} |
| 数据 | {来源、样本量、划分方式、是否跨被试} |
| 预处理 | {在哪一步做，如何避免泄漏} |
| 指标 | {主指标 + 次要指标 + 区间} |
| 停止条件 | {跑几次/多久就停} |
| 失败判据 | {什么结果算失败} |
| 资源 | {GPU/时间/标注成本} |
| 记录 | {种子、环境、数据版本、日志路径} |

## 排查顺序（结果不对时）

1. 数据泄漏 → 2. 标签 → 3. 划分 → 4. baseline 实现 → 5. 指标 → 6. 超参 → 7. 假设。

## 预期与替代

- 预期：{…}
- 若不成立：{这本身是不是一个可报告的边界条件}

## 下一步

- 今天（30 分钟）：{跑通最简单的 baseline}
- 本周：{完成主实验第一轮}
- 两周：{消融 + 失败案例分析}

## 需要你确认

{最多 1 个问题，例如样本量是否够}

> 本文件由 AI 辅助整理，引用与数据请自行核验；不替代导师意见与学校规范。
```
