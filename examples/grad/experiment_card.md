# 实验卡：跨被试压力识别与个体校准

**一句话判断**：这个实验能验证 H1，前提是自采标签的一致性达标；最大风险是回顾性自报带来的标签噪声（置信度 65%）。

**为什么**：WESAD 上可以先把 LOSO 管线和基线跑通，再把同一套流程搬到自采数据；这样即使自采失败，论文仍有公开数据上的完整结果。

## 假设

- H1：在 LOSO 划分下，加入个体基线校准的模型显著优于同一模型不做校准。
- 推翻条件：校准后的 F1 提升不显著，或提升只出现在少数被试上。
- 机制假设：跨被试损失主要来自个体生理基线差异，而不是活动干扰【推测】。

## 设计

| 项 | 内容 |
| :--- | :--- |
| 自变量 | 有无个体校准；特征模态（EDA / HR / ACC / 全部） |
| 因变量 | 压力二分类的 F1、准确率、校准误差（ECE）、置信区间 |
| 对照 | 被试内上界；手工特征 + 逻辑回归；随机森林；端到端一维 CNN |
| 数据 | WESAD 公开数据；自采 10–15 名同学，E4 采集 EDA/HR/ACC |
| 划分 | LOSO 为主；被试内为参考上界；严禁先归一化再划分 |
| 预处理 | 1 Hz 重采样；滑动窗口 60 秒、步长 30 秒；按被试做 z-score |
| 标签 | 自报压力（0–10）二值化；两人独立标注 20% 样本，算一致性 |
| 停止条件 | 每组配置固定 3 个随机种子；调参不超过 20 组 |
| 失败判据 | 标注一致性低于可接受水平，停止扩充自采，改用公开数据完成论文 |
| 资源 | 无 GPU；CPU 训练，单次实验控制在数小时内；E4 两套 |
| 记录 | 种子、环境、数据版本、日志路径全部写入实验记录 |

## 主要比较

1. 手工特征 + 逻辑回归（最简单强基线）。
2. 手工特征 + 随机森林。
3. 原始信号 + 一维 CNN。
4. 在 3 的基础上加个体校准层。

**先跑 1 和 2**。如果简单基线已经接近复杂模型，贡献叙事要从"新模型"改成"评测与边界分析"。

## 结果不对时的排查顺序

1. **数据泄漏**：归一化、特征选择、窗口重叠是否跨了训练/测试边界？
2. **标签**：二值化阈值是否合理？两人标注一致性多少？
3. **划分**：LOSO 是否真的按被试隔离？有没有同一被试出现在两边？
4. **baseline 实现**：随机森林超参是否默认？CNN 是否训练不足？
5. **指标**：类别不平衡时只看准确率会误导；补 F1 和校准误差。
6. **超参**：固定种子跑 3 次，报告均值与区间。
7. **假设**：以上都正常，可能个体校准的作用被高估——这本身是可报告的边界。

## 预期与替代

- 预期：校准能挽回一部分跨被试损失，但校准数据越少越容易过拟合【经验】。
- 若不成立：把论文改为"跨被试压力识别的失效边界与评测协议"，仍是完整工作。
- 不做的事：不为了让结果显著而反复换指标；不删失败被试。
