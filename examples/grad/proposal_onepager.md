# 跨被试学业压力识别：开题一页纸

**一句话判断**：题目成立，但要把"识别压力"收窄成"跨被试、自然学习场景下的稳定识别与边界分析"（置信度 70%）。

**为什么**：你的资源能支撑 10–15 人的小样本自采和公开数据实验；真正的贡献不在模型，而在一套可复现的跨被试评测和失效边界。最大的风险是标签一致性，不是算力。

## 1. 现象与缺口

大学生学业压力普遍存在，但靠自报量表只能做事后回顾，无法连续监测。可穿戴设备可以连续采集皮肤电、心率、加速度等信号，压力识别研究已积累较多方法【文献】。现有工作多在实验室诱发任务或特定职业场景中验证，被试内性能通常高于跨被试【文献】；公开数据集 WESAD 提供了较完整的多模态信号，但采集以实验室压力任务为主【文献】。真实学习场景下的个体差异、活动干扰和标签稀疏，目前缺少系统评测。

## 2. 研究问题

- 主问题：在跨被试、自然学习场景下，哪类生理信号与建模策略能提供稳定的学业压力识别？
- 子问题 1：跨被试条件下，性能下降主要来自个体基线差异还是活动干扰？
- 子问题 2：少量目标被试数据做校准，能恢复多少性能？

## 3. 假设（可证伪）

- H1：在 LOSO 划分下，加入个体基线校准的方法显著优于不做校准的同一模型。
- H2：EDA 相关特征在跨被试场景中的贡献大于 HR 和 ACC；若消融显示相反，H2 被推翻。

## 4. 方法

- 数据：WESAD 公开数据 + 10–15 名同学的自采数据（E4；EDA、HR、ACC；自报压力标签）。
- 预处理：按被试划分后再做归一化，避免泄漏；滑动窗口提取时域与频域特征。
- 模型：手工特征 + 树模型作为强基线；一维卷积网络作为对照；个体校准层作为方法改动。
- 评测：LOSO 为主，被试内为上界参考；报告准确率、F1、校准误差与置信区间。
- 对照：简单规则、逻辑回归、随机森林、端到端 CNN。

## 5. 证据标准

- 支持 H1：校准后在 LOSO 上的 F1 提升，且置信区间不跨 0。
- 推翻 H1：提升不显著，或只在个别被试上有效。
- 失败判据：自采标签的两人一致性低于可接受水平，则停止扩充数据，改用公开数据完成论文。

## 6. 贡献

1. 在学业学习场景下提供一套跨被试压力识别的评测协议与可复现基线。
2. 给出个体校准对跨被试性能的定量影响，并分析其适用边界。
3. 公开预处理与评测代码，使后续工作可直接比较。
